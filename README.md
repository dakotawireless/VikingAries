# Viking Aries Starter

Standalone browser prototype for Viking Aries.

Temporary target domain:
- https://vikingaries.dakotawireless.net

Current prototype includes:
- Personal / Contractor workspace switching
- Project navigation
- Project chat tabs
- Shared-project context indicator
- Right-side live preview
- Preview expand / dock / hide
- Desktop / tablet / mobile preview sizing
- Mobile navigation
- Placeholder sections for Architecture, Integrations, Database, Deployments, Logs, Secrets, and Settings

This is intentionally frontend-only for the first visual iteration.
